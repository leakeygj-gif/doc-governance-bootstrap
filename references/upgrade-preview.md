# 已有项目的只读升级预览

仅在检查版本或准备升级已有项目时阅读。预览不写目标文件、配置或安装副本，不运行业务/硬件脚本，不暂存、提交或推送。

## 分清三个位置

- 开发仓库：记录提交及未提交改动，不能只用提交号代表工作区版本。
- 已安装 skill 副本：读取实际目录；无版本标记时比较内容或校验值，无法定位则注明未知。
- 项目生成文件：读取规则、模板、hook、检查器及配置，识别项目定制。

三个位置不自动同步。无可靠基准时报告“版本未知”和具体差异，不猜版本号，也不把所有差异都视为旧版缺陷。

## 预览步骤

1. 读取目标 Git 状态、有效 hooksPath、hook 权限及相关规则，不改变它们。
2. 对照拟采用模板逐文件列出当前行为、拟采用变化、项目定制及来源、建议保留/合并/替换、风险与待确认项。
3. 保留已确认的安排，例如模块到规格映射、重复试验沿用计划、只用 AGENTS.md 而不建立 CLAUDE.md。找不到来源时标待确认，不自动覆盖。
4. 可在目标上只读运行检查器，记录命令、解释器、退出码与分类疑点。不为输出归零批改历史。审阅产物只写本次已获授权的位置。
5. 提供具体拟写路径、范围和验证方式，确认后实施。安装副本更新与项目写入分别列明，确认其中一个不代表另一个获授权。
6. 交付分别报告文件变化、hook 配置、隔离测试与项目未验收项；不能以副本更新宣称所有项目同步。

| 文件/配置 | 当前差异 | 定制与依据 | 建议处理 | 风险/待确认 |
|---|---|---|---|---|

本流程不提供自动升级器，不建立新状态平台；只读预览不要求另造版本文件。
