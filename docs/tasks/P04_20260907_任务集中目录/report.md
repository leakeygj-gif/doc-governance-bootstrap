## 使用约定

新任务默认一个 `docs/tasks/P编号_日期_名称/` 目录，内含plan.md、report.md。专用脚本、manifest及小型结果就近保存；文件少时无需tools/data子目录。实际重复使用才考虑提取公共工具；已有共享工具、产品源码和大型原数据保留原位置，由任务引用。
检查器仅扫描tasks根历史文档，以及一级P编号任务目录的直接文档。阶段可用 `阶段名.report.md` 并链接plan.md；资料子目录不用于嵌套任务。已完成计划需有有效关联报告。
