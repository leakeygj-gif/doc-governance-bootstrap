## 目标
移除无须公开的外部项目验证资料与个人信息，保留可复用的技能、模板、工具、测试和设计理由，并将同一远端仓库公开。

## 确认记录
用户于 2026-09-07 确认清理后公开；前述方案已说明不备份、移除原始验证资料、重写远端历史和最终公开的不可恢复风险。本计划按该授权执行，不另建备份。

## 边界与禁区
仅修改本仓库文件和本仓库 Git 历史、远端可见性；不修改其他项目、安装副本或全局配置，不安装依赖。保留 MIT 许可及公开账户署名。不伪造已移除的历史证据；含隐私的报告撤下并以明确标注的公开说明替代。不得把文件清理完成写成发布已完成。

## 分步计划与门禁
1. 文件门禁：移除外部私有样本、快照和关联敏感信息；保留通用测试，修正引用，更新日志与登记表。全套单测、任务关联、符号、有效文档链接、敏感词及凭据模式检查通过，人工复核后进入第 2 级。
2. 历史门禁：基于通过检查的工作树建立没有旧父提交的单个根提交，使用公开 noreply 身份；核对完整文件树、作者信息、分支及标签，确认旧历史不再由待发布引用可达。
3. 远端门禁：重新读取远端分支基准，以精确 force-with-lease 替换同一远端分支；远端发生并发变化即停止；替换后核验远端提交及引用，并以旧提交 API 检查敏感对象是否仍可访问，若仍可访问则保持私有并记录阻塞，不进入第 4 级。
4. 公开门禁：切换仓库为 Public，核对远端 API 可见性、默认分支与公开文件内容；记录实际发布结果。检查失败则保持当前阶段，不跨级执行。

## 风险
不创建备份，被删除证据与旧历史可能无法恢复；模式扫描不保证发现所有秘密。远端隐藏引用及服务商缓存不能仅靠分支替换证明清除。旧历史改写会改变提交编号，旧协作者克隆不应直接推回。
