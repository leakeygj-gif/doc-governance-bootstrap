## 数据来源与前提
用户明确确认同名重建、不备份，并完成 GitHub 本人身份验证。承接[文件阶段](report.md)与[首次发布门禁](publish.report.md)，两份定稿报告保持原样。上传来源为本地已清理 main，上传时为 2 个干净提交、48 个文件，作者与提交者采用公开 noreply 身份；不推送其他引用。

## 方法
先将修订方案和确认记录写入计划。复核旧远端没有并发变更，通过浏览器已登录会话进入删除流程；本人身份验证后观察到删除成功提示，API 返回 404。使用 CLI 同名创建独立私有仓库，确认新 ID 不同且非 fork，不初始化额外文件，只推送 main。私有阶段检查旧提交及旧敏感文件不可访问后切换 PUBLIC。匿名验证使用不加载 curl 配置、不附带认证头的系统 curl，保留 TLS 证书验证。Python urllib 因本机证书链校验失败未完成请求，改用系统 curl，未关闭证书验证。

## 本次算不了的
接口不可访问证明本次新仓库下已识别旧对象不能通过这些接口读取，不等于托管方物理对象、所有缓存或用户此前下载副本均已销毁。本地既有应用引用和 reflog 未销毁，禁止将这些旧引用推回新仓库。没有创建备份、扩大令牌权限、安装依赖、修改全局配置或其他项目。新仓库 ID 与设置已重建，不保留旧仓库系统关联。
